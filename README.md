# Resonance

A minimal page for looking up the tempo of a track, built against the
[GetSongBPM](https://getsongbpm.com) API.

> **Status: stub.** This repo currently holds the landing page and the API
> attribution that GetSongBPM requires of anyone using their data. The lookup
> itself is not implemented yet.

## Why the attribution is in the markup

GetSongBPM issues API keys on the condition that you link back to them from the
page using their data. That backlink is the reason this page exists in its
current form, so if you fork or restyle it, keep the credit line intact or the
key stops being valid.

## Running it

```bash
open index.html
```

No build step and no dependencies.
